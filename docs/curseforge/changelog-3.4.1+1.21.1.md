## Beach Craft (Raft) 3.4.1 for Minecraft 1.21.1

**This is the Minecraft 1.21.1 version of Beach Craft 3.4.1** (Fabric Loader 0.16+, Fabric API 0.116.x for 1.21.1), with the same change as 3.4.1 for Minecraft 26.3.

- **Item tags have names now**: JEI, REI and EMI show "Grill Fuel", "Island Seeds", "Fishing Bait", "Cooking Pot Seafood", "Tide Sigils" or "Shell Armor Repair Materials" instead of raw ids like `#raft:grill_fuel`. All 63 item tags of Beach Craft got a readable name.

Worlds from 3.4.0 for 1.21.1 load as they are.
